# 多语言迁移验证

验证日期：2026-10-09。使用系统 pnpm 9.15.4、Node.js 22.23.2。

## 实现范围

项目统一使用 Vue I18n 11.4.13 的 Composition API、稳定文案键、中英文资源与英文回退。旧英文词表文件、英文原文匹配函数和递归翻译参数的适配函数已删除；源码及最终注册表均无旧入口引用。

默认示例在文案定义处翻译；外部标签、代码、命令、文件名、用户输入和业务字符串原样显示。组件 ID、变体、类型、列和标签标识与展示文案分离。默认示例的搜索通过 Vue I18n 显式读取中英文资源，仍支持中英文查询。路由标题使用稳定键，画廊元信息保留响应式 getter，注册表构建固定生成英文元信息。

修复了流程图尺寸和球数、微调卡片宽高、推荐卡备选方案与表格辅助标签遗漏；编辑后的计算提示词在切换语言时保留。默认流式示例切换语言保持进度及完成状态，调用方更新真实内容时重新触发完成周期。

## 本轮自动化与运行验证

- `pnpm test`：8 个文件、138 项既有测试通过。未新增测试用例；仅将既有国际化断言调整为稳定键与已本地化的默认标签。
- `pnpm build`：Vue 类型检查、33 个组件注册表生成与 Vite 生产构建通过。
- 注册表检查：33 项 JSON 与索引、源码一致；包含国际化模块的 21 项声明 `vue-i18n@^11.4.13`；旧入口引用为零。
- 临时消费项目提取最终注册表的 33 项、97 个独立文件，导入全部组件并设置中文；独立 `vue-tsc --noEmit` 与 Vite 构建通过。复用本机依赖，未执行真实 shadcn CLI 安装。全部组件合并为一个入口时 JS 约 677 kB，产生 500 kB 分块提示；主站构建无此提示。
- 临时运行探针：非循环流式组件先后传入两段内容，完成回调执行两次，与原版一致；工具代码与文件标签 `Text` 在中文模式保持原样。

## 本轮浏览器验证

在本机浏览器检查了中文流程图菜单的尺寸和球数、微调卡片的宽高与辅助标签、推荐卡备选方案正文。编辑记录表格的计算提示词后通过键盘双向切换语言，面板继续打开，自定义文字保留。最终生产预览另行确认宽高标签、中英文搜索与流程图选项的双向切换和选中状态；页面日志未捕获警告或错误。

最初中文实现已有桌面与手机布局、21 个画廊条目及 16 个变体、明暗主题、十种 Harness 场景、中文输入法事件和状态保留的验证记录。上述历史检查不等同于本轮重新逐一手动验收，也不能替代未来新增语言的排版验收。

## 验证边界

验证在本机完成，未运行远端 CI 或部署生产。邮箱订阅仍使用模拟测试，没有发送真实订阅。输入法防误提交使用组合事件与 keyCode 229 验证，未逐一检查各操作系统实体输入法。Harness 是本地脚本演示，其多语言界面不代表真实模型或业务接口的多语言能力。
