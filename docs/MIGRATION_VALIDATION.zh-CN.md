## 实现范围

独立实现 Vue 3 + Vite + TypeScript + Tailwind CSS 4 应用，包含 11 个 atoms、22 个 primitives、21 项画廊组件及 16 个变体选项、许可证页面和 Harness 的 10 个脚本场景。使用原生 Vue JSX / SFC，没有 React、React DOM 或 Next.js 运行时依赖，也没有指向原版仓库的运行时导入或符号链接。

主题、字体、图片、源码查看与复制、组件安装说明、邮箱界面、音效和 Canvas 图表均随项目提供；订阅 API 由独立 Node 服务实现。Harness 和录音输入保留脚本演示语义，不代表真实模型、供应商或麦克风服务集成。

## 已知差异与验证边界

- 商业 Central Icons 替换为本地 SVG，保持尺寸和语义，部分字形不同。
- React Agentation 替换为 Vue 本地反馈工具，提供选元素、填写反馈和复制功能，没有外部服务集成。
- Fontsource 本地字体与原版在线字体版本可能存在细微光栅差异；Surfer 视频仍依赖原版远端服务。
- 订阅 API 使用模拟 Resend 响应验证，未执行真实联系人写入；未进行音效听觉确认、所有浏览器覆盖或生产部署验证。
- 已确认继承的上游问题留待后续修复：审批自定义文本未传递给提交回调、关闭审批后待执行的自动提交未取消，以及快速切换图表后旧子项残留。现有 83 项测试未覆盖这些边界。
